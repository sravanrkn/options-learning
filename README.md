# options-learning

Learning options trading from scratch, in public.

One lesson at a time: curated free sources → explain it back → pass a quiz → publish a short
AI-made explainer video. Later: paper trades, then (carefully) real ones. Notes, scripts and
video links are published here as each video goes out.

**Status:** curriculum drafted, Lesson 1 in preparation. Nothing published yet.

## How it works
- A lesson is done only when the quiz is passed 100%.
- Videos lag two lessons behind, so each one doubles as revision.
- No margin. No real money until a full quarter of paper trades has been reviewed.

## Contents
- `curriculum.md` — the lesson index (published lessons link from here)
- `lessons/` — published notes, scripts and video links
- `PUBLIC-CHECKLIST.md` — what is and isn't published here
